长会话不再变慢

这一版大部分工作在做同一件事：让一个跑了几百轮的对话，和刚开始时一样快、一样准。旧工具的结果会被收起来、按需取回，上下文满了会先压中间、留住最近一轮，子代理的上下文和主对话彻底分开。另外新增了会话导出、审批说明和一组更严格的命令安全判断。

新功能
- 导出会话：对话右上角可以导出一个 ZIP，里面是完整记录、子代理的记录，以及会话期间留下的文件。用系统的保存对话框选位置；`/export` 在输入框里也能做同样的事。单个文件太大、或者总数超过上限时会被跳过，并告诉你有几个。
- 审批说清楚是什么：每次请求批准，面板上会标出风险等级（读取、写入、破坏性、凭证、联网）、这个改动能不能撤销，以及工具来自哪里。破坏性和凭证类的还会多一句为什么——比如「删掉的是驱动器根目录、系统目录或用户目录」「碰到的是密钥或密码文件」。请求和决定都记进审计日志。
- 浏览器工具在完全访问下也会问：读取已登录页面的 cookie、localStorage，或者拦截、修改它的请求，即使在「完全访问」模式下也要单独确认。
- 查看 MCP 服务器提供了什么：在 MCP 服务器那一行点开，能看到它暴露的工具、资源和提示词，以及最近一次的错误——不用离开对话就能判断它为什么不工作。
- 带回另一个对话说过的话：消息里引用一个已保存的对话（`[Session id: title]` 的写法，输入框插入的就是这个），它的最新几条消息会一起带进去，标成背景而不是指令。最多三个来源，每个 8000 字符。
- 这一轮改了什么、交付了什么：助手交付文件时会显示成卡片。活动栏把「这一轮改的文件」和「更早轮次留下的」分开列，都带行数。
- 手机上能看到上下文用量：会话更新会带上窗口大小、已用多少、从哪开始压缩、压缩过没有。旧版桌面端不发这些字段，不认识它的手机端会忽略。

改进
- 长会话的上下文管理，这一版重做了：
  - 工具结果先剪中间再清空：超过 8K 字符的旧结果先只保留开头和结尾，够用就不清空；不够才按调用分组清掉更早的。恢复会话时按同样规则重现。
  - 压缩时给回答留位置：压缩阈值会预留模型回答的空间（最多 21K）和请求本身的空间（13K），窗口再小也不会压到一半以下。摘要之后最近一轮对话原样保留，调用和它的结果不会被拆开。
  - 模型可以自己整理上下文：它有一套不出现在对话里的工具，能把一段对话折起来换成摘要、再取回来、搜索、查看用量、取回被收起来的工具结果。对话里只显示一条提示，不显示这些调用。
  - 折叠只改它覆盖的那一段，后面的提示词缓存不受影响。
  - 反复调用会提醒：同一个调用做到第 3、5、8 次时，会提醒模型换个办法。
  - 工具有了时限，WebFetch 给 90 秒；很大的 Bash 结果会整份留着，等上下文机制去收纳，占位符里同时给出头尾。
- 子代理的上下文和主对话彻底分开：每个子代理有自己的用量、待办、已读文件和压缩计数，它的摘要不会再进到主对话的上下文里。
- 失败会分类处理：能分辨限流、过载、上下文溢出、鉴权和证书问题，并各自给出该怎么做。摘要、标题、分类这类小任务遇到过载会立刻放弃，不再反复重试。
- 空回答会重试：流里一个字都没出来的，单独算作空回答，只重试两次而不是耗掉整个预算；一轮结束既没有文字也没有调用，重试两次后给出提示。
- 压缩比例和余量可以调，可以全局设也可以按模型设；上下文超长时的压缩重试次数也能设（默认 1 次）。
- 危险命令的判断更严：新增 git 的硬重置、清理和强制推送，`find -delete`、`rsync --delete`、Windows 的递归删除，以及套在包装器里的命令（`sudo`、`env`、`timeout`、`xargs` 等）。PowerShell 的参数缩写（`-fo` 就是 `-Force`）、`& { }` 调用块和 `$( )` 子表达式也会拆开看；`iex (iwr …)` 这种下载即执行会识别出来，并且不给「总是允许」的建议。
- 凭证目录和密钥算作受保护路径。
- 会话恢复时按记录重建已读状态，宿主也可以通过 `seed_read_state` 预设。
- 不再留着用过的工具输入：长会话里每次调用的入参（一次写入的整个文件、一次编辑的两个字符串）在结果回来后就不再保留，只有后台命令、子代理和计划的还会再读。
- 搜索更快：用一份内存里的词索引先筛出可能命中的对话；筛不出来的查询（词的一部分、或者谁都没有的）仍然照旧全扫，不会漏。
- 自动模式在别的上游模型上也能用：Claude Code 自己的分类器不跑的模型（其他上游的、或者它不支持的），由 BaoCode 用该上游的小模型来判断，CLI 那边则被告知去询问。
- 会话恢复后不再覆盖这里选的审批方式；换模型时会把模式重新发过去。
- 自动模式会提示哪些「总是允许」规则会让它失效（比如 `Bash(bash:*)` 这种等于放行一切的规则不再出现在建议里）。
- 输入框的增强（Enhance）在空项目里也能用了：以前项目里没有可参考的文件时，模型会写出一整篇计划而不是改写消息，被「太长了」拒掉之后不再重试。现在这种情况会改问不带项目的版本。

修复
- 侧边栏搜索、会话列表在很长的记录上不再卡顿（只读文件头尾）。
- 子代理卡片只保留最近 200 步，并告诉你省略了多少步。
- 代理开或关的切换会立刻传到正在跑的 CLI。
- 连按三次以上失败后压缩会停下，不再空转。
- 「完全访问」在 Windows 上真的是完全访问：CLI 在 Windows 上没有 root 检查，之前被不必要地降级成了「接受编辑」。
