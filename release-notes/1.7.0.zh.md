诊断、bots，和更顺手的应用

这一版主要在说两件事：出了问题能查到，平时不挡路。卡住或崩溃会留下可以看、可以发出去的报告，界面不再时不时冻住几秒，Enhance Prompt 也从一两分钟降到十几秒。另外新增了 bots——像和人聊天一样跟它说话的 agent，手机上就能用；还有一条中继，让手机在任何网络下都能连回这台电脑。

新功能
- Bots：像和人聊天一样说话的 agent，在手机上使用。每个 bot 有自己的名字、头像、性别、签名和说话风格，模型也可以单独选。它能看 agent 的对话、在项目里开一个新对话、像你一样给 agent 发消息、读项目文件、用浏览器、生成图片，也能在有事发生时先开口（一次运行结束了、失败了），每天最多几次，安静时段不打扰。它自己的图片和表情包会显示在聊天里。
- 手机从任何网络连回来：两边互相看不见时，由中继转发手机的连接，不用开放端口，也不用公网地址。桌面端自己拿着中继地址和只有它知道的 token；数据在到达中继之前就已经加密，中继读不到内容。设置 → 手机 里能看到桌面端这一头的状态。
- 诊断：应用卡住或一次运行不正常结束时，事件日志会记下是怎么结束的；macOS 上会把系统的卡顿和崩溃报告连同日志一起收集，卡住时还会采样调用栈，并把 Dart 的帧对应到源码。在设置 → 诊断 里可以一次性发出去。
- Git 图：泳道不再截断在 12 条，提交详情可以选中复制，分支名按原样显示——名字里带斜杠的本地分支不再被当成远程分支。
- 提交面板：每个改动前有一个复选框，文件列表可以切换成列表或树，还能只按勾选的改动生成提交信息。
- 会话侧栏的文件树会显示每个文件的 Git 状态；改动过的 markdown 文件按渲染结果显示，点一下就切到 diff。
- 回复里的 Mermaid 图会画出来，并且会告诉 agent 聊天界面能渲染什么，让它写出能显示的内容。
- 查找和搜索支持跨行：粘贴进去的多行文本按原样能找到，分成两行的短语也能搜到。
- 用键盘缩放界面、恢复默认大小；界面尺寸的变化会连同原因一起记进事件日志。
- IDE 活动栏底部加了设置齿轮。
- 手机端能看到工具调用带回来的图片、浏览器每一步做了什么、agent 的目标和当前轮次进展，以及每条 bot 消息的发送时间。

改进
- 不再卡住：读取系统代理时会在界面线程上执行一条命令，现在放到别处执行，不会再冻住窗口。截图和构建启动的进程也一样。
- Enhance Prompt 快了很多。实测六次里有三次返回过长，而这三次恰好是最慢的——其中一次耗了两分钟才放弃。现在会要求它按提问的体量来写，写超了会在生成过程中就停下。
- 浏览器的大消息不再每收一块就把整个缓冲区复制一遍：20MB 从 5.5 秒降到 0.3 秒。
- 复制回复时保留 Markdown 原文：长文本粘贴回来不再被截成「[Pasted text #1 +660 lines]」。
- 用 GBK 编码回应的 MCP 服务器能正确读出内容，不再乱码。

修复
- 模型把 token 数写成字符串（"input_tokens": "1234"）时不再报错。
- 正在编辑的消息保持是编辑框那一行，不会被缓存的旧气泡盖住。
- 输入法在选中文字上组合输入时替换选中内容，而不是两者都留下。
- Windows 上浏览器后台程序读到过期的 TEMP 目录时，现在能找回正确的端口。
